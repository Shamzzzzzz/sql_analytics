# sql_analytics
### Сессионализация пользователей (Sessionization)

Написал SQL-запрос, который разделяет действия пользователей на отдельные сессии. Если между двумя событиями проходит больше 30 минут, начинается новая сессия.

Для этого использовал CTE и оконные функции `LAG()` и `SUM() OVER()`. В результате каждому событию присваивается `session_id`.

Такой подход позволяет анализировать количество сессий, активность пользователей и их поведение в продукте.


###sql_analyze_month
Описание
SQL-запрос для анализа динамики месячной выручки за период с января по май 2024 года.

Цель: определить месяцы, в которых выручка увеличилась по сравнению с предыдущим месяцем.

Логика запроса

Расчёт выручки с учётом количества проданных товаров и скидок.

Агрегация выручки по месяцам.

Сравнение текущей выручки с предыдущим месяцем с помощью LAG().

Вывод только тех месяцев, в которых наблюдался рост выручки.

Используемые технологии
PostgreSQL: CTE, JOIN, SUM(), DATE_TRUNC(), COALESCE(), LAG(), GROUP BY.

Бизнес-ценность
Позволяет выявлять месяцы с положительной динамикой выручки и отслеживать изменения финансовых показателей бизнеса.
