# sql_analytics
### Сессионализация пользователей (Sessionization)

Написал SQL-запрос, который разделяет действия пользователей на отдельные сессии. Если между двумя событиями проходит больше 30 минут, начинается новая сессия.

Для этого использовал CTE и оконные функции `LAG()` и `SUM() OVER()`. В результате каждому событию присваивается `session_id`.

Такой подход позволяет анализировать количество сессий, активность пользователей и их поведение в продукте.
